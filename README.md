# Visual Lab

Пять интерактивных визуализаций на одной статической странице: клеточный автомат,
математическая поверхность, гипотеза Коллатца, фрактальная черепаха и симулятор слота.
Всё считается в браузере на чистом JavaScript и Canvas 2D — без библиотек, сборки и CDN.

**Демо:** https://testsoulja.github.io/visual-lab/

## Разделы

| № | Демо | Что внутри |
|---|------|------------|
| 01 | Муравей Лэнгтона | Клеточный автомат 150 × 100, правила поворота, «шоссе» после ~11 000 шагов |
| 02 | Поверхность `z = sin(√(x² + y²))` | Программный 3D-рендер: ортографическая проекция, сортировка граней по глубине, вращение и масштаб |
| 03 | Гипотеза Коллатца | Последовательность 3n + 1, график, логарифмическая шкала, поиск пика |
| 04 | Фрактальная черепаха | Точный перенос `turtle`-алгоритма на Canvas: 1001 отрезок, угол растёт до 250-й итерации, затем убывает |
| 05 | Симулятор слота | Три барабана, ставка 1000, таблица выплат 1:1 из Python-версии |

Демо запускаются лениво: секция активируется, когда попадает в зону видимости,
и ставится на паузу при уходе с экрана. Поддерживается `prefers-reduced-motion`.

## Структура

```
index.html              страница и разметка всех демо
assets/style.css        тёмная тема и адаптивная сетка
assets/app.js           реестр демо, ленивый запуск, подсветка навигации
assets/demos/ant.js     муравей Лэнгтона
assets/demos/surface.js 3D-поверхность
assets/demos/collatz.js гипотеза Коллатца
assets/demos/turtle.js  фрактальная черепаха
assets/demos/slot.js    симулятор слота
python/                 оригинальные Python-скрипты (для сравнения)
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Для проверки ссылок на Python-файлы
можно поднять статический сервер:

```powershell
python -m http.server 8123
# http://127.0.0.1:8123/
```
